# 🧪 Swag Labs Automation - Cypress (DIO Challenge)

Este repositório contém o projeto de automação de testes para a plataforma [Swag Labs (Sauce Demo)](https://www.saucedemo.com), desenvolvido como parte de um desafio prático da **DIO (Digital Innovation One)**. O objetivo é validar os principais fluxos de uma plataforma de e-commerce.

## 🎯 Objetivo do Projeto
Demonstrar a aplicação de testes end-to-end (E2E) em um ambiente real, garantindo que as funcionalidades de compra e navegação funcionem sem erros.

## 🛠️ Tecnologias Utilizadas
*   **[Cypress](https://www.cypress.io)**: Framework de automação de testes moderno e rápido.
*   **JavaScript**: Linguagem de programação para escrita dos scripts.
*   **Node.js**: Gerenciamento de dependências e ambiente.

## 📝 Cenários Testados
O projeto cobre os fluxos críticos da jornada do usuário:
1.  **Autenticação**: Login com diferentes tipos de usuários (sucesso e erro).
2.  **Gestão de Produtos**: Adição e remoção de itens do carrinho de compras.
3.  **Fluxo de Checkout**: Preenchimento de informações e finalização da compra.
4.  **Filtros**: Ordenação de produtos por nome e preço.
